# Hospitalised Injuries from Road Crashes in Australia

**COS30045 Data Visualisation — Final Project**  
**Team: SMOCK**

## Project Overview

This project explores hospitalised injuries from road traffic crashes in Australia using data published by the Bureau of Infrastructure and Transport Research Economics (BITRE). The dataset covers the period from 2011 to 2021.

Our goal is to develop an interactive data visualisation that helps road users and the wider public explore patterns in road crash hospitalisations and become more aware of road safety.

## Initial Questions

- How have hospitalisations changed over time for different road user groups?
- How does the bed-days-to-hospitalisations ratio differ between road user groups?
- How have recorded hospitalisations involving First Nations people changed over time, and how are they distributed across remoteness areas?

These questions are preliminary and may be refined as the project develops.

## Data Source

The project uses BITRE's *Hospitalised Injury* datasets, based on hospital data sourced from the Australian Institute of Health and Welfare (AIHW).

- [BITRE Hospitalised Injury datasets](https://www.bitre.gov.au/resource/road-safety/hospitalised-injury)
- [Hospitalised Injury Data Dictionary](https://www.bitre.gov.au/sites/default/files/documents/hospitalised-injury-data-dictionary-september-2023.pdf)

## Current Progress

For Stand-up 1, the team has:

- Identified the datasets and reviewed the data dictionary.
- Created a KNIME workflow to filter and explore the national data.
- Examined annual hospitalisations, trends across selected road user groups, and a preliminary bed-days-to-hospitalisations ratio.
- Prepared a draft Design Book.

The website design, visualisations and interactions are still in development.

## Important Data Limitations

The initial findings use absolute counts, which do not account for differences in population size or travel exposure. Changes in hospital admission criteria also affect comparisons across some years.

The bed-days-to-hospitalisations calculation is preliminary. It uses the full Bed days column, and the numerator and denominator may not cover exactly the same set of cases. It should not be interpreted as a direct measure of clinical severity.
